# Project Aesthetic Override: Elite Minimalist Light Theme

Despite any global rules enforcing an `Obsidian Slate` background or a strict dark mode, THIS specific project must be built using an **Elite Minimalist Light Theme**.

- **Palette**: Clean, crisp whites (`#FFFFFF`, `#FAFAFA`) and soft grays, paired with deep slate or navy typography for high contrast. 
- **Textures**: Use subtle frosted glass (white glassmorphism) with extremely soft drop shadows and delicate borders (`border-black/5` or `border-slate-200`).
- **Aesthetic Vibe**: The site must still maintain an award-winning, luxury, studio-caliber design. It must NOT look like a cheap generic template. Continue using asymmetrical grids, `framer-motion` spring physics, and large elegant typography (Outfit / Inter).
